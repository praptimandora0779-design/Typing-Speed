# ⌨️ AI Typing Test

A modern **Typing Speed Test** built using **HTML, CSS, and JavaScript**. It measures typing speed, accuracy, and mistakes with a clean AI-inspired interface.

## 🚀 Features

- 🎲 Random paragraph generator
- ⏱️ 60-second countdown timer
- ✅ Real-time correct & incorrect character highlighting
- ❌ Mistake counter
- ⚡ Words Per Minute (WPM)
- 🔤 Characters Per Minute (CPM)
- 🎯 Accuracy calculation
- 🔄 Try Again button
- 🎉 Test completion popup
- 📱 Responsive UI

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)

## 📂 Project Structure

```
AI-Typing-Test/
├── index.html

├── script.js
└── README.md
```

## ▶️ How to Run

1. Download or clone this repository.
2. Open `index.html` in your browser.
3. Start typing and track your performance.
